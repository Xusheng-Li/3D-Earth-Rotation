# 3D-Earth-Rotation
This project is a 3D Earth rotation experiment demo developed using C++ Builder and the FireMonkey (FMX) 3D framework. By applying Earth surface textures and background images, the program renders a 3D globe and demonstrates real-time self-rotation. It is suitable for computer graphics courses, 3D visualization learning, and teaching demonstrations.
🌍 3D Earth model rendering based on FMX 3D
🔄 Continuous Earth self-rotation animation
🖼️ Support for Earth surface textures and starry background
🪟 Runs on Windows x64 platform
📚 Clear structure, ideal as an introductory 3D graphics experiment
